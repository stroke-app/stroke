### New Features

#### Updates
- Updates download in the background and install when you quit, so the next launch is the new version
- The status bar offers Restart to update once a download is ready
- A What's new dialog lists the changes since the version you were on, after every update
- Turn background downloads off in Settings, General, Updates

### Changes
- .deb, .rpm and Scoop installs still ask before updating, since they install through their package manager
