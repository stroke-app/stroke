### Bug Fixes
- On Windows, pressing F6 no longer blanks the Stroke window and leaves it impossible to close
- On Windows, F5 in a text field, Shift+F5, Ctrl+F5, and Ctrl+R with a dialog open no longer reload the whole app and drop the connection
- On Windows, F7, F3, Ctrl+G and Ctrl+S no longer open the browser's caret browsing prompt, find bar or Save As dialog
- On Windows, if the webview crashes for any other reason, the window gets its native title bar back so it can still be closed
