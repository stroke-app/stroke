Terminal: the dock showed an empty space after turning Animate panels off, because a slide-out from before stayed applied. Panels now drop any leftover slide. psql sessions send TCP keepalives (30 s idle, 3 misses), so an idle session behind a NAT or cloud firewall stays open, and a dead one reconnects instead of hanging on "Cancel request sent". Animate panels is now off by default everywhere, and installs that still had it on switch off once.
